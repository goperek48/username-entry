One word, one username, one reward: this entry sends the entrant's own
make.fun username — `muse` — and nothing else. A single word, four
characters, no spaces, no padding, no gloss tacked on.

- `main.py` — the entrypoint. Validates the username the way the gate
  scorer will (UTF-8 text, 1–30 characters, a single word) and writes
  it byte-exact to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
